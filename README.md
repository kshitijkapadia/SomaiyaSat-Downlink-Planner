# SomaiyaSat Downlink Planner

## Project Description
SomaiyaSat Downlink Planner is a Python-based simulation that manages satellite packets during a ground communication pass.

## Features
- Add satellite packets and generate sample packets.
- Prioritize packets according to their importance and urgency.
- Simulate a 60-second ground pass.
- Check signal strength and available transmission time.
- Store packet and pass information using SQLite.
- Generate an HTML website report.

## Technologies Used
- Python
- Tkinter
- Object-Oriented Programming (OOP)
- SQLite
- HTML and CSS

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run `python main.py`.
5. Use the application to add packets and simulate a ground pass.

## Project Scope
This project is a simulation for educational purposes. It does not connect to a real satellite or ground station.
## Project Structure

- `main.py` - Main application entry point
- `models.py` - Project data models
- `database.py` - Database operations
- `website.py` - Website-related functionality
- `index.html` - Web interface
